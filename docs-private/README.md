# 私有材料入口

按「读者能不能用它做事」分线，而不是按文档类型：

- **公开**（`README.md`、`docs/`、`release-notes.md`、`AGENTS.md`、`NOTICE.md`）：已发生的事实——怎么用、怎么回事、怎么验收、已知限制。
- **私有**（本目录）：排期与推进过程、逐版本维护日志、本机环境取证、被否决的方案、原始调试产物。

结论稳定后升级为公开条目，避免两份事实。本目录默认不入库（`.gitignore`），只保留本说明。

## 现在放在这里的东西

| 目录 | 内容 |
|---|---|
| `maintenance-*.md` | 逐 issue / 逐版本的维护过程记录（结论已在 `docs/` 与 `release-notes.md` 里） |
| `upstream/` | 上游 README 快照（含本仓库没有的 `docs/preview/*.png` 引用），只作对照，不对外发布 |
| `evidence/` | 样式审计脚本的原始取证（`*-raw.txt`）与研究报告定稿前的中间稿 |
