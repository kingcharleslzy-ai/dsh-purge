# Purge 面板二维布局设计稿 v3（实现稿）

版本 3.0 · 与 `packages/purge-panel` 的实现一致 · 宿主 DeepSeek Harness Desktop 0.2.2-rc.1 · 插件 dsh-purge-community 1.6.93

## 1. 破局点

前两版都只是把纵向堆叠的卡片排进网格，骨架仍是「一行一块」的线性流。

真正的二维平面要解决的是：面板里最重的两类数据本来是**行列表**（72 条补丁、25 层自检），表格和长列表才是滚动与堆叠的根源。

破局动作：**把行列表压成二维点阵**。

| 数据 | 旧形态 | 新形态 |
| --- | --- | --- |
| 72 条补丁 | 折叠表格，纵向 72 行 | 5 条分组轨道，每条一行，方块一字排开 |
| 25 层自检 | 折叠列表，纵向 25 行 | 按类别 4 条泳道，点阵排布 |
| 顶部状态 | 一条横向文字带 | 4 个并列状态槽 |

点阵用颜色承载状态，不依赖数字阅读。悬停出名称。

## 2. 平面结构

```
┌ 页头（不占网格）
├ 状态槽行：DSH 宿主 │ 兼容级别 │ 插件 │ 运行来源   （4 等分，竖分隔线，无边框）
├ 页签
└ 网格（12 列，列间隙 12px）
    ├ 应用操作条        span 12
    ├ 补丁矩阵          span 12
    ├ 破甲自检          span 7    ┐ 同一行
    ├ 版本              span 5    ┘
    ├ 破甲强化段        span 4    ┐ 同一行
    ├ 逐层说明（折叠）  span 4    ┤
    └ 高级选项（折叠）  span 4    ┘
```

轨道与泳道是「行」这一维，点阵是「列」这一维。二维信息在两维同时展开。

## 3. 网格系统

页面主体 12 列网格，列间隙 12px，左右内边距 24px，卡片内边距 12px×16px。

| 区块 | 跨度 | 高度 |
| --- | --- | --- |
| 状态槽行 | 12（内部 4 等分） | 76px |
| 应用操作条 | 12 | 61px |
| 补丁矩阵 | 12 | 190px |
| 破甲自检 | 7 | 166px |
| 版本 | 5 | 135px |
| 强化段 / 逐层说明 / 高级选项 | 4 各一 | 47–71px |

窄于 1100px 时所有区块回落到单列，状态槽变 2×2。

## 4. 点阵规格

**补丁矩阵**

- 每个补丁一个 10×10 方块，圆角 3px，间隙 3px，用 `repeat(auto-fill, 13px)` 定宽网格排布。
- 颜色：已应用 `--dsw-alias-state-success-primary` 22% 底 + 62% 边框；待应用 `--dsw-alias-state-warn-primary` 20% 底 + 实心边框；没对上 / 锚点漂移 `--dsw-alias-state-error-primary` 20% 底 + 实心边框；虚线框表示按选择关闭；灰底表示本机不适用。
- 每条轨道左侧是组名（72px 固定列），中间是方阵，右侧 168px 是计数与异常摘要。
- 悬停方块出补丁名与状态。

**自检泳道**

- 每层一个 8px 圆点，间隙 6px，`repeat(auto-fill, 15px)` 定宽网格。
- 颜色同上语义。
- 泳道名（宿主 / 运行时 / 配置 / 布局）固定 48px 列，右侧 42px 是通过数。

## 5. 状态槽

4 个槽等宽，槽内是「标签 + 值」两行，值 0.98em 半粗。槽之间用竖分隔线，不画卡片边框。状态点 7px 圆点在标签前。

槽内容：DSH 宿主版本、兼容级别、插件版本、运行来源。

「磁盘写入计数」从状态槽删除，补丁矩阵一处承担。

## 6. 提示位置

| 提示 | 位置 |
| --- | --- |
| 兼容级别含义 | 状态槽内该标签右侧 ⓘ |
| 补丁写入口径 | 应用操作条内，「写入后需退出并重开 DSH」右侧 ⓘ |
| 补丁名与状态 | 补丁方块悬停浮层 |
| 层名与计数 | 自检圆点悬停浮层 |
| 强化段作用 | 强化段标题右侧 ⓘ |

## 7. 嵌套层级

卡片只一层边框。轨道行、点阵、状态槽均无边框。折叠块内是行，不是卡片。嵌套不超过两层。

## 8. 其他页签

| 页签 | 布局 |
| --- | --- |
| 提示词 | 编辑器 span 8 │ 注入说明 span 4 |
| 规则 | 工作区策略 span 3 │ 本地规则 span 4 │ 规则集 span 5（内含列表与编辑器并排） |

## 9. 验收结果

- 1440×690 视口下，状态页的操作区、补丁矩阵、自检结论、版本信息同屏可见，无滚动。
- 72 条补丁与 25 层自检不展开、不滚动即见全貌。
- 悬停任一补丁方块或自检圆点可读到名称与状态。
- 规则页三栏并列，714px 内容高度落在 690px 首屏内。
- 浅色与深色主题下方块、圆点、按钮对比度均可辨。
- 循环依赖 0；视图层与状态流程层分离，视图模块不含请求逻辑。
