# Purge Community 1.6.11 acceptance record

## Fix scope

- #12: the `/rewind` name conflict is fixed according to the author's later corrected reproduction, keeping the original owner and registering a Purge fallback command. The panel is not restored by disabling rewind or by process-level timer polling.
- #15: read the correct permission node; the actual default permissions at runtime take precedence over on-disk literals. `inferred` / `unknown` are kept separate from `broken`. CLI JSON/text exit codes agree; a zero exit code does not mean everything is verified.
- The read-only status endpoint does not depend on the connection/session being ready; late services, replacement, parent plugin reloads, and uninstall are all disposed by Cordis, leaving no global timers.
- YAML is parsed as data only and never executes `!!js`. User permissions are not changed automatically. Host patch definitions and existing features are preserved.
