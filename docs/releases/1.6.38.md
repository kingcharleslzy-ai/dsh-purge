# Purge Community 1.6.38

- #44 / PR #47: the official release package download budget is configured separately, defaulting to 180 seconds; added a URL-prefix mirror that is off by default. The mirror transfers TGZ only, SHA256 comes from official channels, and tokens are never sent to the mirror. Download or checksum failure no longer triggers an install rollback.
- PR #45: removed duplicate configuration edits before entry creation, preserving the full plugin definition, user overrides, and old package migration behavior.
- PR #46: completed owner handling for the audit directory, existing logs, and files created after rotation, kept private permissions, rejected symlinks and hard links, and a permission error while reading no longer shows an empty log.
- Real-machine install acceptance found and fixed an issue where a Windows short path/directory alias made the pnpm cache filename for a rollback package too long; the real path is resolved before handing it to the package manager, preserving the original archive, configuration, and failure recovery.
- Added real Linux root/service-user permission tests, actual DSH configuration composition, and three-platform official npm host install, upgrade, rollback, and failure-recovery acceptance. The existing Electron and feature regression gates remain.

Existing prompts, presets, proxies, and update preferences are unchanged; host patches are not auto-applied and DSH is not auto-quit or restarted. Thanks to alexopenfan-xiaxin for the reproduction and three PRs; the integrated version tightened the proposed checksum sources and file ownership boundaries.

Configuration method, scope, and rollback cautions are in [maintenance notes](../maintenance-issues-44-47.md).
