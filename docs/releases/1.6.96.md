# 1.6.96

- Preset compatibility no longer depends on a `0.2.2-rc.*` version whitelist; it reads the control main entry's capability instead: migrate the old entry only while `list_agents` is still registered.
- It works automatically when a future 0.2.x keeps merging; if the provider stops being offered, the old entry is kept, surfacing the host error instead of silently deleting a tool.
- Added regressions for a future version and for the provider disappearing; local preset conversion is still 1 → 0.
- Host source patches can still drift as upstream rewrites them, requiring `diagnose` / reanchoring; zero maintenance cannot be promised.

Verification: the full suite passes.
