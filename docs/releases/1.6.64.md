# 1.6.64

安装时的完整历史备份改为可明确选择的保护步骤，不再将普通备份目标写入失败一律当作安装失败。

- 首次安装没有旧插件时，不创建空的旧版快照；现有依赖的安装失败恢复仍保留。
- 旧版升级遇到已识别的备份目标写入错误（权限、只读、空间不足、路径冲突），面板允许确认后继续；CLI/安装器提供绑定本次包和配置的确认值。
- 自动更新不会接受这项风险；确认不保存为永久开关，更换安装包或配置后须重新确认。
- 来源读取失败、哈希读取失败、安全软件拦截、UNKNOWN、关键配置错误及安装失败恢复准备失败仍阻止继续。不会关闭防护、设置排除、跳过安装验证或将不完整备份列为可回滚。
- 在线更新不再重复创建快照或在安装事务已处理失败后再执行一次回滚；安装错误和恢复结果继续明确报告。
- 成功但没有完整快照时，面板和 CLI 明确说明日后回滚限制。现有设置、提示词、功能和代理保留，不自动重启。

Defender 对既有技能文档的检测没有在本版中被豁免或宣称误报。验证范围见 [维护记录](docs/maintenance-1.6.64.md)。
