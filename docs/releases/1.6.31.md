# 1.6.31

## Fix #38: default preset selfcheck false positive

After 1.6.30 tightened the counting, the skip state of #76 — which the default preset never needs to execute — was counted as a fault. This release adjusts read-only diagnostics only and does not change the host patch table, matching rules, user presets, prompts, or permissions.

- For #76's ambiguous skip state, statically parse the preset body under the current DSH_HOME; after confirming persona.prefix is a literal without the target sentence, show "no handling needed" and do not count it as applied or as a required failure.
- Not all optional/skipped entries are excluded. A target sentence still present with a mismatched anchor keeps reporting an error; pending still shows pending; a missing required file still warns.
- Corrupt YAML, duplicate fields or persona, dynamic expressions, inheritance/aliases, unreadable files, and undecidable structures show unknown; expressions are not executed and other profiles are not scanned in place of the current file.
- Keep the user's existing settings and all functionality; do not auto-apply host patches or restart DSH.

## Verification

New combined regressions cover default preset LF/CRLF, comments, an empty prefix, pending, existing markers, residual identity sentences, anomalous YAML, dynamic expressions not executed, read failures, and genuinely missing targets. The tests call the real #76 state detection and then pass through selfcheck aggregation, so the default path and the error path are covered together. Official release is still gated by Linux/macOS/Windows tests.

Local macOS: 212 tests, 207 pass, 5 platform skipped; Windows 11 real-machine isolated directory: 212 tests, 209 pass, 3 platform skipped, including real TLS/proxy and Electron handoff. Real Electron 44.7.0 selfcheck passes on both ends. Test scripts were fixed to exit the test child process before deleting the temporary ASAR on Windows, without changing host handoff logic. The Windows release smoke also passes, the test script's way of invoking npm.cmd directly was fixed, and packaging checks were added to the PR and release CI on all three platforms.
