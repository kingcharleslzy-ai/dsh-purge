# 1.6.74

Fixes the 1.6.73 newline-escape error that prevented DSH from starting, and completes message/prompt error propagation and install troubleshooting, keeping the original decision logic and user settings.

- Correct the #67 patch template that mistakenly wrote a literal `\n`, with the comment swallowing the next line and causing the `Missing catch or finally after try` startup failure. Only the newline is corrected; the original condition is unchanged; existing corrupt artifacts can be migrated exactly, and diagnostics no longer treat their marker as success.
- When a message callback lacks an array, return an explicit `PURGE_INVALID_PRE_STEP_DECISION` instead of silently becoming empty input. Explicit refusals are preserved as is; legitimate empty arrays and normal messages keep their original semantics, and message bodies are not printed in errors.
- When a native prompt provider or assembly callback fails, keep the original exception and its code/cause instead of returning an empty prompt, empty tool list, or stale assembly result. Normal requests recover once the problem is removed.
- Adopt the direction of PR #131's archive warning and documentation guard, preserving the contributor's original commits; correct the advice to delete a whole configuration block. Verify the profile, dependency alias, and bundle first, migrate only confirmed duplicate entries, and keep all original configuration and other plugin entries.
- The documentation guard parses the actual YAML examples, covering quoted/unquoted entries, submodules, misplaced warnings, and missing examples; ordinary prompts and error explanations are not misjudged. Migration and rollback preservation tests are part of the default suite.
- Added isolated Electron checks against the real official 0.2.2-rc.1 prompt/persona/scope services, included in Mac and Windows CI.

## Verification and unresolved items

Local full regression: 512 passing, 21 conditionally skipped; the 13 message/error contract tests and 7 real native service check groups pass in isolated Electron on Mac and the Windows 4090. Checks cover first turn, second turn, scope switching, parallel and sub-scopes, exception propagation, and recovery after fault removal. No model was called, and this does not represent full GUI preset selection or end-to-end acceptance of all plugins.

This release only fixes #67's newline escape and corrupt-artifact migration; other host patches are unchanged, and it does not carry 1.6.73's other host adaptations or full-feature acceptance conclusions. The existing Windows 4090 Defender full-rollback blockage and the unconfirmed #127 item are outside this fix.

Thanks to @longyanbo1224-debug for PR #131's archive documentation improvements.

The local fault file and patch template were backed up before being fixed, and settings file checksums were unchanged; the user confirmed recovery after manually reopening, and the backend health check passed. No global "disable plugins" was used and nothing restarted automatically. Detailed evidence in the [runtime verification record](https://github.com/kingcharleslzy-ai/dsh-purge/blob/v1.6.74/docs/native-input-integrity.md).
