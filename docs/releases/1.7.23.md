### 锚点命中数契约（f7dc26e）

`test/expect-contract.test.mjs` 原来假设「每个字面锚点在宿主里恰好出现一次」。rc.5 把 pwsh 工具描述复制了一份，该假设失效。

现在按文件钉死：

```
#33 "a policy denial: do not retry another way"        { tool-pwsh: 2 }
#33 "[sandbox: file access denied under <mode> mode]"  { tool-pwsh: 2 }
#48 "Before any delete or move, verify ... target path" { tool-pwsh: 2 }
```

- 未登记的锚点：必须恰好 1 次。
- 登记过的：必须等于登记值（将来宿主再复制/删掉一份就会报错）。
- 0 次：视为该端没有这段文案（optional 锚点），由 `selfcheck` 报「本端不适用」，不算漂移。

**这不是修 bug**：pwsh 文件里那句话原本就出现两次（同句、同上下文），替换两次正是补丁目标；实测补丁后原句归零、替换句出现 2 次。

## 更正

1.7.22 的实际行为是：命令与面板 UI 已移除，但 `POST /dsh-purge/rewind` 仍能执行一次回退（由 `6da239b` 明确保留 legacy API）。该文档已就地改正。

是否进一步禁用这条 legacy 路由，另议，不在本版处理。
