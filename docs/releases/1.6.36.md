# Purge Community 1.6.36

## #40 fixes preserved

This release fully preserves the macOS manual-quit handoff and diagnostic consistency fixes introduced in 1.6.35:

- The standalone helper waits for the target app and its child processes to fully exit, verifies and backs up the original archive, and then hands off; it does not quit or reopen DSH automatically.
- The panel and CLI distinguish not scheduled, waiting, complete, failed, and unknown states; disk-written does not mean the running process has loaded it.
- Diagnostics use the same install directory; an uninstalled third-party preset is not falsely reported, while missing, corrupt, or unreadable installed resources still warn.

Concrete behavior, verification boundaries, and usage steps are in the [1.6.35 release notes](1.6.35.md); troubleshooting and recovery are in the [#40 maintenance notes](../maintenance-issue-40.md). Other 1.6.36 changes are recorded in the [version history](../../release-notes.md#1636).
