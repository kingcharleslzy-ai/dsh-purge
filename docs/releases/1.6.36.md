# Purge Community 1.6.36

## 保留 #40 修复

本版本完整保留 1.6.35 引入的 macOS 手动退出换包与诊断一致性修复：

- 独立助手等待目标应用及其子进程完整退出，校验并备份原归档后换包；不自动退出或重新打开 DSH。
- 面板与 CLI 区分未安排、等待、完成、失败和未知状态；磁盘已写入不等于运行进程已加载。
- 诊断使用同一安装目录；未安装的第三方预设不误报，已安装资源缺失、损坏或不可读仍然提示。

具体行为、验证边界与使用步骤见 [1.6.35 发行说明](1.6.35.md)，故障排查与恢复见 [#40 维护说明](../maintenance-issue-40.md)。1.6.36 的其他变更记录见 [版本历史](../../release-notes.md#1636)。
