# 1.7.13

- **More accurate update diagnostics (#225)**: when a response exceeds the size limit, the limit and the known size are shown; when both the primary and fallback sources fail, or only a stale cache exists, the check result is marked unknown while keeping the last confirmed version, and a stale cache never triggers an automatic install. When the full list is unavailable, the current stable version can be queried read-only from GitHub for confirmation, but it is not treated as an installable target.
- **Release notes split per version (#225/#226)**: the GitHub Release body now uses `docs/releases/<version>.md` instead of accumulating history again; a single-version summary is capped at **8 KiB**, and publishing is refused beyond that.
- **Version numbering rule (#222)**: patch numbers use 0–99 without leading zeros; the historical 1.6.100/1.6.101 keep their original tags and bodies.
- Existing download limits, origin verification, SHA256 checks, and host patches are unchanged.
