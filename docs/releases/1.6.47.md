# 1.6.47

Fix #68: entry location missed the electron-vite desktop layout, so #82/#83/#84 were falsely reported missing.

- Read `main` from the selected install's `resources/app/package.json` first, accepting old `main.js`, `lib/main.js`, and `out/main/index.js`, `out/main/main.js`. Selfcheck, diagnostics, and apply share one resolver.
- An explicitly declared but missing/unreadable entry does not fall back silently; out-of-bounds paths, links pointing outside, and undeclared layouts with multiple entries keep the fault. It does not search another installation or mark a real gap green.
- Diagnostics provide the `desktop_entry` resolution state and source. Existing patch content, optionality, and error ranking are preserved.
- Added old/new layout, declaration-priority, residual entry, anomalous manifest, path boundary, cross-instance isolation, and real Electron apply/re-apply/selfcheck/diagnose tests; verified the correct target is still read when ASAR and a physical directory coexist.

Existing features, prompts, and settings are preserved, and DSH is not auto-restarted. Includes 1.6.46's junction cleanup fix; Windows users on 1.6.45 and earlier should still upgrade through the new standalone installer to avoid old processes running old cleanup code. Thanks to @zebulonpeng for the reproduction.
