# 1.7.25

## 这一版修什么

主要是**归属与认证**，不涉及补丁清单（仍是 74 条，其中 61 条本机适用）。

### 桌面更新与诊断入口（#344）

- 尊重 **desktop CLI 归属**：不再把 Electron 管理的 profile 当成可随意改写的 CLI 实例。
- 恢复「经校验的工作区迁移」：迁移前先证明目标是我们要动的那份，失败不会留下半截状态。
- 诊断信息仅 owner 可读；非 owner 只看到匿名拒绝结果。
- 更新失败会在回滚**之前**先被演练（`scripts/check-retired-permission-upgrade.mjs`），避免"回滚了才发现新包也是坏的"。

### 面板认证（#335）

DSH **0.2.3** 下，管理类 HTTP 路由要求 Host owner 准入。旧代码在拿 `connection.authentication` 时用的是固定上下文，0.2.3 会解析失败并回 401。

现在改为**按调用方 fiber** 解析，凭证从实际发起连接的那条链路取，不再依赖全局状态。

### 其它

- 权限恢复脚本在 Linux 与桌面 runner 上都跑（`470a5ae`）。
- 包归属校验（`e7f7d1d`）：装卸前确认包确实属于本 profile。
- `package-lock.json` 版本字段与 `package.json` 对齐（#342）。

## 与 1.7.24 的关系

1.7.24 删掉了 14 条权限/沙箱/审批补丁，边界交回宿主配置。这一版**没有把补丁加回来**，只修归属与认证——如果你的 profile 是全权限，行为与 1.7.24 一致。

## 升级

装好后重启 DSH。若状态页出现「迁移未收敛」，点一次「应用」再重启，让宿主文件与插件记录对齐。
