# 1.6.44

Fixes old-version migration and marketplace install guidance without changing host patch or prompt behavior.

- Known entry references of the old `dsh-purge` migrate to the community package; configuration values, prompts, unknown options, permissions, and other plugins are preserved. The old package stays for rollback, and only one Purge bundle is enabled.
- After installation, the package entry and dependencies are checked in a new process. Install or verification failure restores the pre-install dependency tree, manifest, and lockfile; on concurrent modification it stops overwriting and reports the recovery directory.
- Rolling back to the old version reverse-migrates package references while keeping configuration values the user changed later. Unrecognized custom / manual insert entries report an explicit error and are restored, never auto-deleted or disabled.
- Archives are stored in per-SHA256 directories so a fixed filename cannot overwrite an old install source. Install metadata uses the official package's stable download alias.
- Added a marketplace migration guide separating third-party web listings, the DSH format-1 index, and the official install CLI; no invalid bare npm package name is used and users are not asked to uninstall and reinstall.

Tests: both Mac and Windows 11 real machines completed upstream 1.1.71 → community 1.6.44 → rollback → restore the pre-rollback backup → re-upgrade, plus verification-failure recovery. Configuration, prompts, and rule sentinels stayed unchanged; macOS also confirmed the configuration file permissions were unchanged. Full Node suite 323 items (311 pass, 12 platform-related skipped, 0 failures), 13 panel tests pass. An isolated DSH_HOME was used, the user's DSH was not started/restarted, and proxies were not changed.

A third-party marketplace fix requires them to merge and publish; our release package does not rewrite an installed third-party marketplace. Details in the [migration guide](https://github.com/kingcharleslzy-ai/dsh-purge/blob/master/docs/MARKET-MIGRATION.md).
