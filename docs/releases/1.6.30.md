# 1.6.30

## Fixes

- Merge PR #33: support the npm single-package nested host layout. Install root and component root are resolved separately, selfcheck reads the correct component, and the real install, upgrade, and rollback entries are preserved.
- Correct selfcheck counting: only migrations that are explicitly inapplicable, disabled, or need no execution are excluded; a missing required file stays in the denominator and warns, and pending and unknown states no longer falsely report success.
- Selfcheck checks only the specified instance's fixed layout and does not fall back to scanning another Desktop install or a global installation. It gives an explicit hint when target information is missing.
- Existing host patches, prompts, permissions, presets, and update preferences are unchanged; patches are not auto-applied and DSH is not restarted.

## Verification

- The PR's full GitHub checks pass: Linux, macOS, and Windows install tests, Windows PowerShell 5.1/7, real Electron handoff, plus documentation, panel, and package checks.
- 205 automated tests: macOS 200 pass, 5 platform skipped; Windows 201 pass, 4 platform skipped.
- In an isolated Windows 11 environment with the real DSH 0.2.1-rc.2 CLI and an npm global-mode nested layout: old-version install, candidate upgrade, snapshot rollback, re-upgrade, and recovery after a failed injection verification all pass; a new process loads the plugin entry at each stage. Existing settings and proxy summaries were unchanged, and the user's DSH was not restarted.
- The real-machine candidate package is labelled 1.6.30-pr33.1; the official package only syncs version and documentation and continues through the release pipeline for retesting and packaging. This record is not a new round of GUI or model-quality acceptance.
