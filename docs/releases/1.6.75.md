# 1.6.75

Fixes install location, marketplace compatibility declarations, and the mirror update channel, preserving user configuration and existing features, without automatic restart.

- #130: compatible with the new and old Desktop CLI, manifest bin, and the new shell's Node entry; recognizes the host version inside an archive, distinguishing not-yet-unpacked from genuinely missing. The runtime no longer falls back to unrelated installations from the workspace, profile dependencies, or the home directory.
- #132: adds a savable HTTPS mirror setting covering update queries and archive transfer. Tokens are not sent to the mirror or its redirects; official installation still requires independently reading official digests and verifying the pinned repository's release origin. When official verification is unreachable it fails explicitly instead of substituting a mirror's self-reported digest.
- #137: the marketplace index reads each version's own compatibility declaration, fixing 0.2.2-rc.1 being rejected by an old hard-coded range. Historical versions without a declaration keep their original range.

## Verification and scope

**Known limitation**: the Mac isolated install transaction passes and GitHub's three-platform checks pass; a fresh install on the maintainer's Windows 4090 is still blocked by Defender quarantining an existing skill file, so that machine cannot be claimed as fully installed, upgraded, and rolled back. The maintainer knew of this limitation and approved the release; this release does not mean the blockage is resolved.

See [maintenance notes](../update-layout-130-132-137.md) for the verification record. Install, runtime diagnostics, network transfer, and model effect are recorded separately; not all host patches are claimed as adapted. User settings, proxies, the official DSH installation, and its process are not modified.
