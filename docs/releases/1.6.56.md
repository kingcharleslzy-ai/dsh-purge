# 1.6.56

- **Status page performance (PR #82)**: a single read-only diagnostic shares host identity, install root, and path resolution, reducing repeated disk calls. The cache does not persist across queries, so a handoff, deleted file, or retargeted link cannot leave stale evidence in use.
- **Status errors (#83)**: identical concurrent status requests are merged; timeouts, non-JSON, and API errors keep their reason and show "status unknown", no longer falsely reporting `0/0` or "host not located". Refresh can retry, and real gaps and patch drift keep showing.
- **Theme contrast (PR #81)**: the drill console search button and report step numbers use paired theme colors, updating both the community build and the standalone panel build.
- Existing patch definitions, prompts, presets, settings, and permissions are preserved; nothing is auto-applied nor DSH restarted.

## Verification and boundaries

Full regressions, native Electron status API, and Mac/Windows isolated install, migration, rollback, and failure-recovery acceptance records are in [maintenance notes](../maintenance-issues-81-83.md). The #83 screenshot false positive is reproduced; the old-version Windows status query stall is reproduced, but the reporter's full 60-second timeout still needs their OS/DSH version and post-update result, so the issue stays open.
