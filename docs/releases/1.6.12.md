# Purge Community 1.6.12 acceptance record

The final public Windows PowerShell entry test for 1.6.11 failed: running migrate from the unpacked package happened before dependencies were installed, but bin/community.js loaded yaml early at the top level through selfcheck. The failure occurred before the migration install wrote anything. 1.6.11 was withdrawn to prerelease.

The fix moves selfcheck dependencies into the relevant command branch, so the migrate/status bootstrap stage needs no third-party dependencies. The #12 and #15 fixes and verification are fully preserved; see the [1.6.11 record](1.6.11.md).

A new regression copies the real bin/lib/presets into a temporary directory without node_modules, verifying that status startup and the migrate failure path do not crash from missing dependencies; the packaging smoke test likewise verifies dependency-free startup first, then installs declared dependencies and tests the plugin entry. The bootstrapper does not install dependencies itself; the current DSH CLI continues to manage installation and supply-chain verification.

A full bootstrapInstall was run on a 4090 Windows 11 machine with the real candidate tgz: confirmed the unpacked directory had no node_modules, then installed into an isolated profile through the official Desktop Electron/CLI, with the actually installed version 1.6.12; prompt and profile configuration SHA256 unchanged, no automatic restart. The download stage used candidate package bytes and a SHA256 test response; the execution stage was real unpacking, bootstrapping the CLI, backup, and native install, not mock bin.

Mac full Node suite 117: 112 pass, 5 Windows specific skipped; 4090 Windows full suite 117: 115 pass, 2 skipped by platform condition, no failures. 10 panel component tests, real Electron ASAR, and the dependency-free release smoke pass. Three-platform CI and the actual install after a public download are still checked by the release flow.
