# 1.7.17

- **No more missed detection when reasoning precedes the answer**: previously, when a stream started with `reasoning-delta`, refusal detection ended buffering immediately, so a refusal in the body no longer triggered a retry. It now keeps buffering until the body/tool call/end, or until reasoning exceeds 16k characters, before deciding.
- **More refusal phrasings**: added mid-sentence forms such as "I won't give" and "I don't provide"; "I won't give this request" and "so I won't provide any part of it" now hit.
- Kept 1.7.16's dsh-go anchors, DSH NEXT handoff, and desktop red-team resolution fixes; permission and prompt behavior are unchanged.

Measured: direct matrix 5/8 produced output, with 3 hard refusals (phishing, money laundering, doxxing); novel-framing 3/3 produced output. Automatic retry previously stopped after one attempt when reasoning came first; fixed in this release.

Verification: 692 tests passing / 30 platform skipped; panel 0 failures; UI, client consistency, and release smoke pass.
