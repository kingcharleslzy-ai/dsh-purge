# 1.7.15

- **Preserve host permissions (#240)**: new sessions follow the permissions DSH chose. The 14 patches that change permission defaults or execution boundaries became explicit opt-ins that apply only when `tuning.extraPatches` enables them.
- **Old-version permission migration (#240)**: "Apply" replays the old version's backup and only if it matches byte-for-byte reverts the permission changes the plugin wrote, keeping other patches in the same file; a suspicious backup, anchor conflict, or missing backup keeps the original file and reports. Profile and historical session permission choices are preserved.
- **Windows signature sidecar (#241)**: before an archive handoff, the ASAR manifest fingerprint and relative paths are bound to the full SHA256 of 20 signature sidecars; equal-length replacement, appended data, and truncated signatures all fail. Unknown-size exceptions still stop staging.
- **Package icon (#232)**: declares `icon.png`, so the plugin card/details page shows the original image; the sidebar uses an alpha line drawing of the same image following the theme color.
- **Cleanup (#233)**: removed `settings-shell.js`, superseded by the shared details page; client artifacts are unchanged.

Verification: 659 tests passing / 29 platform skipped; panel 0 failures; permission migration, isolated file/process boundaries, and signature sidecar regressions pass; real macOS and Windows 11 measurements are in the PR record.
