# dsh-purge-community

把 DSH 里拦你的东西拆掉，并把「拆了什么」变成可以核对的事实：宿主补丁、提示词注入、权限配置、无限制预设、规则与技能管理、本机备份与回滚。

## 它做什么

- **宿主补丁（88 条）**：写进 DSH 源码，退出重开才加载；面板的状态页逐条列出生效、待应用、锚点漂移。
- **提示词注入**：`$DSH_HOME/prompt-inject.md` 作为 `dsh-purge` section 每步重贴；正文由你自己维护，插件只读不改。
- **破甲强化段**：默认开，排在最前；顺序可用 `boost-order.json` 或 `PURGE_BOOST_ORDER` 覆盖。
- **权限配置**：profile 的 `cordis.patch.yml` 固定 `danger-full-access` 与 `approval: never`。
- **无限制模式预设**：`unrestricted`，standard 的超集，只改人设，不改工具面。
- **规则集与技能目录**：在面板里增删改，落到当前 DSH home。
- **本机备份与回滚**：应用前建快照，失败可回滚；不覆盖你的提示词与规则。

## 面板在哪

设置 → 插件 → **Purge** 组合包页：正文是配置（状态 / 提示词 / 规则 / 技能 / 更多），标题旁的徽标给出补丁生效数，页面底部是维护区（备份、提示词指纹、Hooks 拦截、安装形态、仓库与许可）。

## 生命周期

安装 → 点「应用」写入补丁 → **完整退出并重开 DSH** → 自检全绿。宿主官方更新、插件升级、新装带工具面的插件之后，都要再点一次「应用」再重开。

## 已知限制

- 宿主补丁写在磁盘上，当前进程不会热加载：不重开就还是旧代码。
- 补丁锚点随宿主版本漂移，`diagnose` 给出漂移位置与半自动重锚入口。
- 「应用」是幂等的，但不会替你重启，也不改你的提示词、规则与其他插件配置。
