# 1.6.64 候选版：安装备份选择与验收边界

状态：**尚未发布。Windows 完整包的正常备份/回滚验收受 Defender 隔离阻断。**

## 行为

- 首次安装无需旧插件历史快照；升级默认尝试完整快照。
- 明确的备份目标写入故障允许用户查看原因及回滚限制后，单次确认继续。确认绑定安装包、profile、清单及配置。自动安装不能接受确认值。
- 源文件读取、校验、UNKNOWN、安全软件拦截、关键配置读取及事务恢复准备失败继续停止。失败快照不进入可回滚列表。
- 安装失败的即时事务恢复与供以后使用的完整历史快照分开；前者仍然必须准备成功。
- 在线更新去掉重复快照及事务外重复回滚，保留安装器原始错误和恢复结果。
- 不改变现有提示词、功能、防护、系统代理或重启行为。

该 Markdown 的既有 PHP webshell 示例内容在核对的历史提交、1.6.60、1.6.61 中一致，SHA256 为 `d70e456d4c0ae0a2b4c2e767dc5c3d0a3131af3be1dc4f3cdc6ed21a8dcd7129`。目前证据不能确定过去未告警的具体原因，也不能代替 Microsoft 对误报的正式判定。未关闭防护、添加排除、恢复隔离文件、改写编码或删除功能来通过验收。
