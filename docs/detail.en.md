# Purge settings

Select **Purge** in the DSH sidebar or open its detail page in the plugin list. Both entries open the same settings. Saved values are available from either entry. Update preferences belong to the current DSH profile.

See the [installation guide](INSTALLATION.md) for installation, migration and rollback. The community edition is maintained by kingcharleslzy-ai and derived from YuJunZhiXue/dsh-purge under the MIT license.
